# TT weboldal

A feltölthető oldal a `website` mappában van.

## Feltöltés webtárhelyre

1. Nyisd meg a `website` mappát.
2. A **tartalmát** (nem magát a mappát) másold a tárhely `public_html` vagy `www` mappájába.
3. A domain gyökerében kell lennie az `index.html` fájlnak.

Ezeket ne töltsd fel: `.git`, `README.md`, `SECURITY.md`.

Szerkeszteni továbbra is a `website` mappában lehet; utána a módosított fájlokat újra fel kell tölteni.
